    Ask the agent

    Follow-ups include the latest completed agent request and reply. Cancel stops subsequent steps; an action already sent to a tool may still finish.

    Results

    Reinsert and Retry let you choose a destination with a hotkey. Result history is kept in memory on this computer until you clear it or quit, unless you choose to save it in settings.

    Dictation & history settings

    Verbatim keeps the transcript wording and punctuation. Clean up removes fillers and stutters. Polished also asks your model to refine it. Vocabulary replacements apply in every mode.

    Persistent mode requires whisper-server on your PATH and a configured whisperModel. It keeps the model loaded between recordings. The first recording loads it.

    A Whisper language code such as en, es, de, fr or ja, or “auto” to detect it. A fixed language is faster and more accurate. Multilingual models only.

    Shares the end of the text you are writing in (never password fields) plus the app type with your model for polished dictation, edits and the agent. No screenshot is taken. Off by default.

    Reminders, Calendar, Notes, Mail drafts, Messages, file search, clipboard and web search. Anything that changes something, or reads your clipboard, asks you first. Mail drafts are never sent automatically.

    With history off, only the latest result is kept for recovery. Results are saved to disk only if you turn on saving, in a file only your user can read.
